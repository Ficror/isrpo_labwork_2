## Общее описание решения
Geometric lib - библиотека на языке python для вычисления площади и периметра различных геометрических фигур
### Выполняемые задачи
- Вычисление площади и периметра треугольника
- Вычисление площади и периметра квадрата
- Вычисление площади и периметра прямоугольника
- Вычисление площади и периметра окружности

## Описание функций
### Triangle.py
1.  `area(a, h)`\
    Возвращает площадь треугольника
    - **Параметры**:
      * a (float) - сторона треугольника
      * h (float) - высота треугольника 
    - **Возвращаемое значение**:
      * $\frac{a \cdot h}{2}$ (float) - площадь треугольника
    - **Пример вызова:**
      ```python
        s = area(4, 5) # - результат 10
      ```
2.  `perimeter(a, b, c)`\
    Возвращает периметр треугольника
    - **Параметры**:
      * a (float) - первая сторона треугольника
      * b (float) - вторая сторона треугольника
      * c (float) - третья сторона треугольника
    - **Возвращаемое значение**:
      * $a + b + c$ (float) - периметр треугольника
    - **Пример вызова:**
      ```python
        s = perimeter(4, 5, 6) # - результат 15 
      ```
### Rectangle.py
1.  `area(a, b)`\
   Возвращает площадь прямоугольника
   - **Параметры**:
     * a (float) - первая сторона прямоугольника 
     * b (float) - вторая сторона прямоугольника
   - **Возвращаемое значение**:
     * $a \cdot b$ (float) - площадь прямоугольника
   - **Пример вызова:**
     ```python
     s = area(4, 5) # - результат 20
     ```
2.  `perimeter(a, b)`\
    Возвращает периметр прямоугольное
    - **Параметры**:
      * a (float) - первая сторона прямоугольника 
      * b (float) - вторая сторона прямоугольника
    - **Возвращаемое значение**:
      * $(a + b) \cdot 2$ (float) - периметр прямоугольника
    - **Пример вызова:**
      ```python
        s = perimeter(4, 5) # - результат 18
      ```

### Square.py
1.  `area(a)`\
    Возвращает площадь квадрата
    - **Параметры**:
      * a (float) - сторона квадрата
    - **Возвращаемое значение**:
      * $a \cdot a$ (float) - площадь квадрата
    - **Пример вызова:**
      ```python
        s = area(4) # - результат 16
      ```
2.  `perimeter(a)`\
    Возвращает периметр квадрата
    - **Параметры**:
      * a (float) - сторона квадрата
    - **Возвращаемое значение**:
      * $a \cdot 4$ (float) - периметр квадрата
    - **Пример вызова:**
      ```python
        s = perimeter(4) # - результат 16
      ```

### Circle.py
1.  `area(r)`\
    Возвращает площадь круга
    - **Параметры**:
      * r (float) - радиус круга
    - **Возвращаемое значение**:
      * $\pi \cdot r ^ 2$ (float) - площадь круга
    - **Пример вызова:**
      ```python
        s = area(4) # - результат 50.2654824574
      ```
2. `perimeter(r)`\
   Возвращает длину окружности
   - **Параметры**:
     * r (float) - радиус окружности
   - **Возвращаемое значение**:
     * $2 \pi r$ (float) - длина окружности
   - **Пример вызова:**
     ```python
       s = perimeter(4) # - результат 25.1327412287
     ```
